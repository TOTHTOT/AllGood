# All Good

> 每天一次问候，让家人更安心。

## 产品描述

All Good 是一款面向老年人及其家庭成员设计的健康打卡与关怀应用。

产品通过简单、低压力的每日打卡，帮助老年人记录用药、血压、血糖、饮食和运动等日常健康信息。应用采用大字体、简洁界面和静音桌面组件提醒，减少复杂操作，为老年用户提供更加轻松、友好的使用体验。

在获得老年用户授权后，子女或照护者可以查看健康记录、接收每日简报，并在发现长时间未打卡或健康数据持续异常时收到提醒，从而及时联系长辈。

All Good 不仅关注健康数据，也希望帮助老年人以积极、平静的态度面对衰老，建立更加规律、有尊严和有陪伴感的生活方式。

## 核心功能

### 1. 个性化健康打卡

用户可以根据个人需求设置每日打卡内容，若手机静音则振动和小组件图片提醒，包括：

- **用药提醒**：可以自定义用药时间，可选响铃和震动提醒
- **血压记录**：量血压时间和高低压记录，子女可以辅助设置（如高压人群和低压人群合理范围不同）
- **血糖记录**：血糖记录可以是实时检测和多次测试相结合，并与饮食记录联动，当高糖饮食超出阈值则报警
- **饮食记录**：拍照记录饮食联动血糖，仅区分高中低糖
- **运动记录**：暂时计划是步数

用户不需要填写复杂表格，只需通过简单按钮完成当天的记录。

### 2. 静音桌面组件提醒

应用可以通过手机桌面组件展示当天任务，例如：

- “今天吃药了吗？”
- “今天测量血压了吗？”
- “完成一次轻松散步吧。”

提醒以视觉方式呈现，避免频繁响铃给老年用户造成压力。

### 3. 家庭关怀模式

在老年用户授权后，子女或照护者可以：

- 查看长辈的每日打卡情况
- 接收每日或每周健康简报
- 查看血压、血糖等数据趋势
- 了解用药、饮食和运动完成情况

健康数据也可以导出，方便在就医或家庭照护时进行参考。

### 4. 异常状态提醒

当出现以下情况时，系统可以向指定联系人发送提醒：

- 在用户设定的时间内没有完成打卡
- 连续多次没有记录用药
- 血压或血糖记录持续超出用户设定范围
- 用户主动发出需要帮助的信号

提醒信息应以“请联系长辈确认情况”为主，而不是直接判断发生了危险。

### 5. 二维码辅助登录

考虑到部分老年用户不熟悉账号和密码操作，All Good 可以支持二维码辅助登录。

子女或照护者完成账号设置后，生成一次性二维码，老年用户扫码即可完成账号关联或登录，降低使用门槛。

## 目标用户

All Good 主要适合：

- 独居或与子女分开居住的老年人
- 需要长期记录血压、血糖或用药情况的人群
- 希望了解父母日常状态的家庭成员
- 协助老年人进行日常健康管理的照护者
